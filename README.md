# Girder Plugin Repository

Questo repository contiene una collezione di plugin per [Girder](https://girder.readthedocs.io/), una piattaforma open-source per la gestione e l'analisi di dati scientifici.

## Plugin

### 🧠 NIfTI Viewer Plugin
Plugin per la visualizzazione e analisi di file NIfTI (Neuroimaging Informatics Technology Initiative) in Girder.

- **Directory**: `nifti_viewer/`
- **Funzionalità**: Viewer 2D interattivo, estrazione metadati automatica, controlli avanzati per imaging medico

### 🔐 OAuth2 Plugin
Plugin per l'autenticazione OAuth2 con supporto per molteplici provider di identità.

- **Directory**: `oauth2/`
- **Provider supportati**: Google, GitHub, Microsoft, Keycloak, Globus, CILogon, LinkedIn, Box, Bitbucket
